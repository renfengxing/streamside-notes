CSV delivery scope

Local delivery only. Provide a redacted CSV sample and expected output through an agreed private channel, never public issues. UTF-8 (BOM allowed), comma-separated files with identical ordered headers only. Exact full-row deduplication preserves first occurrence; whitespace trimming requires explicit consent. Default behavior preserves field whitespace; --trim-fields applies Python str.strip() to value edges before deduplication, never headers or internal whitespace. No fuzzy matching, automatic column filling or blank-value filling. Delivery includes repaired output, a reusable Python standard-library CLI and a JSON exception report. Blank/duplicate headers, mismatched column names/order, wrong field counts, malformed CSV and invalid UTF-8 are rejected without a partial output; existing files are never overwritten. Errors exit nonzero with stderr diagnostics and a JSON error report when its new destination is writable. Output and report must be distinct, new paths and cannot alias inputs. Quoted commas, escaped double quotes, multiline fields and CRLF are supported; output uses LF. Excel workbooks, other encodings and delimiters are outside the CLI scope. No verified online payment integration, customers or income. Solana native USDC is a proposed payment option awaiting integration and verification; no account or transaction is accessed here.
